INPUT: Paper Profile JSON containing:
- software_dependencies (tool names, versions)
- datasets (genome databases, protein databases)
- methods description (from Methods/Supplementary)
- hyperparameters (clustering thresholds, etc.)

OUTPUT: A set of numbered shell scripts and Python scripts that implement the full data pipeline.

PIPELINE STRUCTURE (typical for defense system discovery papers):

1. Genome annotation script (e.g., Prokka, prodigal)

   - Output: .faa (protein FASTA) + .gff (gene coordinates)

2. Defense system annotation scripts
   - Run specialized tools: DefenseFinder, PadLoc, PADLOC, etc.
   - Extract positive labels (defensive proteins)
   - Merge results into unified TSV

3. Negative sample extraction script (Python)
   - Core genome identification (PanACoTA, Roary, etc.)
   - MGE-associated protein identification (HMM scans)
   - Exclude any defensive proteins → negative set

4. Sequence clustering script (MMseqs2/CD-HIT)
   - Multi-level clustering at specified thresholds
   - Extract cluster representatives and membership tables

5. Anti-leakage data split script (Python)
   - Build homology graph from all-vs-all comparison
   - Connected component analysis → homology groups
   - Split by biological category (defense system types, GO terms, etc.)
   - Verify zero cross-fold homology for labeled proteins

1. Each shell script must:
   - Start with #!/bin/bash and set -euo pipefail
   - Accept input/output directories as arguments
   - Log progress to stdout
   - Include exact tool versions from the paper in comments
   - Count results at the end

2. Each Python script must:
   - Use argparse for all parameters
   - Include paper reference in docstring
   - Print progress summaries
   - Handle edge cases (empty results, missing files)

3. Comments must cite specific paper sections:
   ```

   # Ref: Supplementary Materials, Section "Dataset construction", page 7
   ```

